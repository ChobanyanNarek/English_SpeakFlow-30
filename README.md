# SpeakFlow 30

Daily 30-Minute English Mastery PWA (`B1 → B2 → C1`) with Automatic Adaptive Curriculum (Everyday Life, Career, Interviews), Shadowing, Active Output, Roleplay, Speaking/Writing Checks, Spaced Repetition, and 60-Second Blitz Recall.

## Deploy to GitHub Pages

1. Push all files in this folder to a GitHub repository (`main` branch).
2. Open **Settings → Pages** in your repository.
3. Under **Build and deployment → Source**, select **Deploy from a branch** (`main` / `/ (root)`) and click **Save**.
4. Open your published URL (`https://<username>.github.io/<repo>/`) on desktop or mobile and tap **Add to Home Screen** to install as a PWA.
